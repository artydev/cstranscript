Méthodologie : Export, Résumé & Partage

Guide de mise en œuvre pour l'exploitation des transcriptions Whisper RAP

1. Axe Exportation Multi-formats

L'objectif est de permettre à l'utilisateur de récupérer la transcription dans son environnement de travail habituel (Word, PDF, ou Texte brut).

Méthodologie de mise en œuvre :

Génération "On-the-fly" : Utilisation de bibliothèques .NET spécialisées.
  • Word (.docx) : Utilisation de DocumentFormat.OpenXml pour créer un document structuré sans nécessiter Word sur le serveur.
  • PDF : Utilisation de QuestPDF pour une mise en page fluide et moderne.
Intégration HTMX : Dès que la transcription est terminée (état IsProcessing = false), le composant TranscriptionResult affiche une barre d'outils d'exportation.
<button hx-get="/export/docx/{id}" hx-indicator="...">Télécharger Word</button>
Sécurité des téléchargements : Le fichier est généré en mémoire et renvoyé via un FileStreamResult, garantissant qu'aucun fichier sensible ne stagne inutilement sur le disque après l'export.
Stack recommandée : QuestPDF (PDF), DocumentFormat.OpenXml (Word), FileStreamResult (.NET).

2. Axe Résumé Automatique (IA)

Transformer une transcription brute de 30 minutes en un compte-rendu structuré en 10 secondes grâce aux LLM souverains d'Albert.

Méthodologie de mise en œuvre :

Chaînage d'IA (Prompt Engineering) : Envoi du texte transcrit vers l'API Chat/Completions d'Albert (modèle Llama ou Mistral) avec un prompt système spécifique :
"Tu es un assistant administratif. Résume cette transcription en points clés et actions à entreprendre."
Traitement asynchrone : Le résumé est traité comme une seconde tâche d'arrière-plan. On réutilise le même mécanisme de WhisperService (Channel + SSE) pour afficher la progression du résumé.
Structuration Markdown : L'IA renvoie le résumé en Markdown, que l'on transforme en HTML via une bibliothèque comme Markdig avant de l'afficher dans le composant Razor.
Stack recommandée : Albert API (Llama-3), Markdig (Markdown to HTML), System.Threading.Channels.

3. Axe Partage Sécurisé

Faciliter la collaboration entre agents tout en garantissant que les données sensibles ne quittent pas le périmètre de confiance.

Méthodologie de mise en œuvre :

Liens Ephémères (Signed URLs) : Génération d'une URL de consultation unique chiffrée avec une clé secrète serveur et une date d'expiration (ex: 24h).
/share/view?token=ax78...&exp=1708...
Intégration Messagerie (Tchap) : Utilisation d'un endpoint SMTP ou API Tchap pour envoyer directement le résumé à un collègue. HTMX permet d'afficher un mini-formulaire "Envoyer par mail" directement sous le résultat.
Stockage froid temporaire : Pour le partage, les transcriptions sont déplacées du dossier Temp vers une base de données chiffrée ou un stockage objet (S3) avec une politique de suppression automatique (TTL).
Stack recommandée : Microsoft Data Protection API (Tokens), MailKit (Email), Redis ou PostgreSQL (Stockage temporaire).
